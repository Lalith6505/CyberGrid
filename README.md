## 🚀 How to Deploy to GitHub Pages (2 Minutes)

1. Create a new repository on GitHub (e.g. `cyber-grid-protocol` or `cyber-grid-site`).
2. Upload all files from this `github_deploy` folder directly into the repository root.
3. In GitHub, go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your live site and privacy policy will immediately be live at:
   - `https://<your-username>.github.io/<repo-name>/`
   - Privacy Policy URL for Google Play Console: `https://<your-username>.github.io/<repo-name>/privacy.html`
